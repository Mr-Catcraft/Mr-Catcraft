## About

<img align="right" src="./About.png" alt="Mr_Catcraft" width="360" />

I develop backend systems and gameplay extensions for Minecraft. My work is primarily server-side: plugin architecture, mod compatibility, event handling, and data integrity under high load. Java is my primary programming language for Spigot, Paper, and Fabric. I use Python for developing tools, automation, and building backends.

In addition to Minecraft, I write utility programs, experiment with system-level tools in Linux, and study rendering and resource processing in Blender.
